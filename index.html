PERFORMANCE READOUT

60 FPS · 277 draws · 27k tris means 60 frames per second, 277 draw calls and roughly 27,000 triangles rendered in the last second. Draw calls and triangles describe scene complexity; FPS changing while the camera or characters move is normal.

INSTALL

On Android, use the browser menu or the INSTALL button on the title screen. On iPhone/iPad, open Share → Add to Home Screen. The game then launches full-screen like an app.
