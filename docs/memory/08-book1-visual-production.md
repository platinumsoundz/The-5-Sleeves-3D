# Chapter 8 — Book One visual production guardrails

**Source/status:** The 75-page Canva prompt pack v2.0 identifies its prompts as detailed **DRAFT** visual prompts based on Book One Script Reference v1.0 and Canon Bible v2.0. It is not a complete approved manuscript or page continuity ledger. New Canva output is not canon until owner approval. Reconcile page numbers and latest approved art before replacing work.

## How the pack is intended to be used
Use only the prompt for the page being created, with approved character sheets and the latest approved page visible when possible. Do not paste the whole 75-page pack into one generation. Generate clean art first, add approved lettering separately, inspect every exported image. Redo/repair if there are wrong faces, wrong-side/duplicate sleeve, words, speech balloons, watermarks, anatomy errors, panel-order changes, etc. Verify exact 1080×1536 dimensions rather than trusting output defaults.

## Page sequence locks present in prompt pack
- Ajaye has no Cipher Sleeve before the discovery/bonding on Page 8. Once present, on one arm only.
- Korb does not appear Pages 1–30; first appears Page 31, with green Wind Sleeve on one arm.
- Kael's direct confrontation sequence is Pages 51–55, not earlier.
- Cipher does not have genuine spoken conversation before first Sky Tower activation; prompt pack places that first coherent communication at Page 73. Early tech is nonverbal/incomplete.
- The early Book One opening moves from dawn training and household life, to Edge-Rock discovery, return/gate alarm, departure/pack, transit line and barter; later movement introduces Korb and Wind. Preserve order and visual handoff.

## General page continuity checklist
Correct book/chapter/page/title; approved character refs; prior page's state; correct panel count/order/camera progression; only allowed page events; face, hair, body proportions, outfit, props, weapons, pack, injury, Sleeve arm/shape, weather, time and place continuity; exact approved dialogue added only in lettering pass; final panel connects to next page. Preserve geography, hand occupancy, object positions and realistic source/cost for important supplies.

## Global negative requirements
No added dialogue/captions/SFX/page numbers/logos/watermarks/readable signage or UI in art-only prompt pass. No invented lore, visual symbols resembling writing, future characters or revelations early, generic neon cyberpunk, fantasy castles, flying cars, every-location deadly fog, extra limbs/sleeves, mirrored designs, unearned elemental effects or unexplained tech. No text-generated character design in place of sheet.

## Game adaptation boundary
These are comic-specific production rules (portrait page, panels, lettering and Canva workflow). They are not browser-game requirements. Translate character silhouette, material, palette and world tone into procedural blockouts only where appropriate; do not copy page resolution, comic panel composition or art-generation process into Three.js architecture. The current game is intentionally a whitebox.
