# The 5 Sleeves — Training Ground

Serve over HTTP and open localhost:8000. Requires WebGL and Three.js CDN. This is a procedural village mechanics whitebox.

Keyboard: WASD/arrows move, J staff attack, Space jump, K dodge, Shift sprint, Ctrl crouch, E aim/lock, Enter confirm/get up. Gamepad: left stick move, LT aim/lock, RT staff attack, A jump / contextual get-up, B dodge, X interact, L3 sprint, R3 crouch. Touch buttons provide actions. Tutorial can be skipped; Sensei is passive until spar. Knockdowns are nonlethal. XP/currency and Cipher powers are deferred. Performance is unverified. See docs.
