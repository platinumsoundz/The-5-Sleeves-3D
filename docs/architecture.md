# Architecture and safe modification

`main.js` wires the browser loop; `input.js` maps keyboard, standard gamepad and touch; `world.js` builds the procedural arena, drag-orbit camera and responsive viewport; `game.js` owns the skippable tutorial and nonlethal spar; `config.js` contains tuning values. One opponent is supported. Sensei is passive during tutorial. Both fighters can be knocked down; player recovery waits for contextual confirmation. XP/money are deferred; game logic is the future extension point. Cipher powers and story representation are excluded. Browser execution has not been verified.
